开源 · Manifest V3 · v1.0.0

Prompt Manager

一个轻量、隐私友好的浏览器提示词管理器。提示词保存在浏览器本地，不需要账号、服务器或网站访问权限。

下载公开版本查看源码报告问题

高效管理

新增、编辑、收藏、搜索、标签筛选、复制和使用次数统计。

本地优先

仅申请 storage 权限，无网站访问、远程脚本、广告和遥测。

可迁移

支持 JSON 导入导出，便于备份和在设备间手动迁移。

安装

  1. 下载并解压公开版本 ZIP。
  2. 打开 chrome://extensions/。
  3. 开启“开发者模式”。
  4. 点击“加载已解压的扩展程序”，选择包含 manifest.json 的文件夹。

GitHub 下载版需要开发者模式。Chrome Web Store 一键安装版本尚未发布。
